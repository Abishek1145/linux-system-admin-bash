# Linux System Administration Automation Using Bash Shell Scripting

## 📌 Project Overview

This project is a menu-driven Bash shell scripting project designed to automate common Linux system administration tasks.

The script provides a simple menu through which users can perform tasks such as:

- Creating Linux users
- Backing up files
- Checking and installing Linux tools
- Monitoring disk usage

## 🎯 Project Objective

The main objective of this project is to automate repetitive Linux administration tasks using Bash Shell Scripting and reduce the need for manual command execution.

## 🛠️ Technologies Used

- Linux
- Bash Shell Scripting
- APT Package Manager
- AWK
- Linux User Management
- File Management
